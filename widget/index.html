就活管理 ウィジェットの入れ方

次の締切・予定を iPhone のホーム画面に出します(小・中)

  1. App Store で「Scriptable」を入れる(無料)。
    Scriptable を App Store で開く
  2. 下の「スクリプトをコピー」を押す

    コピーするのは40行ほどの短い「読み込み役」です。ウィジェットの本体は、初めて動かしたときに自動でダウンロードされます(あとで本体が新しくなったときも自動で入れ替わります)。コピーできないときは、上の枠を長押しして「すべてを選択」→「コピー」。

  3. Scriptable を開き、右上の「＋」で新しいスクリプトを作り、中を長押しして「ペースト」。上の題名を押して「就活管理」に名前を変え、「Done」。
  4. 一覧の「就活管理」を押して実行すると、ログインの画面が出ます。就活管理アプリと同じメールアドレスとパスワードを入れて「ログイン」。
    パスワードは保存しません。ログインし続けるための鍵だけを iPhone のキーチェーンに置きます。
    このとき本体が自動でダウンロードされ、Scriptable の一覧に「shukatsu-widget-module」が増えます。これは消さないでください。
  5. ホーム画面の何もない所を長押し → 左上の「＋」(または「編集」→「ウィジェットを追加」) → 「Scriptable」 → 小か中を選んで「ウィジェットを追加」。
  6. 置いたウィジェットを長押し → 「ウィジェットを編集」 → Script を「就活管理」にする。
    「When Interacting」は「Open URL」のままで大丈夫です(押すと就活管理アプリの、その予定の企業の画面が開きます)。

ウィジェットは iPhone の都合で 15分〜1時間おきに新しくなります。アプリで完了にしても、すぐには消えないことがあります。小と中を両方置くこともできます。
出るのは「進行中」の区分(秋冬インターン・早期選考など)の、済みにしていない予定です。終了にした区分(夏インターンなど)の予定は出ません。
