# 就活管理アプリ

就活(インターン・早期選考・本選考)の企業・予定・ES・面接対策をまとめて管理する Web アプリ。
GitHub Pages で公開し、データは Firebase(Authentication + Realtime Database)に保存する。

| ファイル | 内容 |
| --- | --- |
| `syuukatu-v3.html` / `.css` / `.js` | **新しい版**。選考区分ごとに整理して管理する |
| `syuukatu-v2.html` | 旧版(夏インターンで使っていたもの)。そのまま残している |

## 新しい版(v3)の考え方

- **企業** … 企業研究・志望の軸・マイページのログイン情報など、区分をまたいで共通の情報
- **選考** … 「企業 × 区分(夏インターン / 秋冬インターン / 早期選考 / 本選考 …)」ごとの
  選考フロー・予定(ES締切・面接など、いくつでも)・ES・面接対策メモ
- 画面上部の区分ボタンで表示を切り替える。終わった区分は設定で「終了」にすると、ふだんの画面に混ざらない
- 1社が夏インターン → 早期選考 と進んだときは、企業の画面の「＋選考を追加」で区分を足す(企業研究は引き継がれ、ES や予定は別々)

画面: ホーム(予定・やること・選考状況)/ 企業(一覧 → 詳細)/ 予定(リスト・カレンダー・タイムライン)/ ES集(全企業の ES を横断)/ 設定

## データの保存場所

- 新しい版: `users/{uid}/v3`
- 旧版: `users/{uid}/data`・`settings`・`todos`(新しい版はここを読むだけで書き換えない)
- 新しい版を初めて開くと、旧版のデータから自動で作る(旧版の「夏/秋/冬」の時期で区分を振り分け。秋・冬 → 秋冬インターン、それ以外 → 夏インターン)
- 保存のたびに、その端末にも控えを残す(サーバー側のデータが消えたときに復元を提案する)
